# versions/v1.0.0 —— 版本记录格式

由 `project-dev` 每次改动新建 `versions/vN/`，至少包含：

## requirement.md

```markdown
# vN 需求

## 原始需求
<用户原话，不要改写>

## 澄清结论
<多轮商讨后的口径；每条写为什么>

## 不做
<明确排除的范围>

## 验收
<怎么算做完>
```

## CHANGELOG.md

```markdown
# vN 变更

## 一、代码变更
| 文件 | 动作 | 原因 |
|---|---|---|

## 二、业务规则
<受影响 block id；无则写「无」>

## 三、验证
| 项 | 命令 | 结果 |
|---|---|---|
（未执行就写「未执行，待验证」，禁止编造通过）

## 四、评审
评审：通过 / 跳过（用户确认） / 待评审
```

## review.md（可选）

评审窗口产出，按 `阻断 / 建议` 分级，每条带 `文件:行号` 与 `代码级` / `需用户定` 标记。

---

> 本目录是**格式说明**，不是某次改动的记录。新项目第一次改动时新建 `v1.0.1/` 开始写。
